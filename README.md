# Mow Pro by UDC Parts

Браузерная 3D-игра про газонную фирму. Работает на телефоне и компьютере, установка не нужна.

**Играть:** https://drongo7777777.github.io/mow-pro/

Ссылка заработает после того, как в репозитории включат Pages: **Settings → Pages → Source: GitHub Actions**. После этого сайт обновляется сам при каждом изменении в `main`.

## Как оставить фидбек

Откройте вкладку **Issues → New issue** и выберите шаблон:
- **Баг:** что-то сломалось;
- **Идея / фидбек:** что улучшить, что скучно, что понравилось;
- **Товар UDC в игре:** добавить деталь, исправить совместимость, добавить косилку.

Скриншоты и видео можно перетащить прямо в форму.

## Как тестировать командой

Каждый играет у себя в браузере, друг другу никто не мешает: игра статичная, сервер общий не нужен. Прогресс хранится в браузере у каждого свой.

**У каждого своя история.** На стартовом экране блок «Who's playing?»: игрок выбирает себя или добавляет новое имя, и у него своя карьера (деньги, день, косилки, репутация, компания «Имя's Lawn Co.»). На одном компьютере или телефоне можно держать несколько игроков и переключаться (Profile → Switch player).

Личная ссылка сразу открывает профиль по имени, её удобно разослать каждому:
`https://drongo7777777.github.io/mow-pro/?player=Anna`

Имя игрока автоматически попадает в форму бага, так что видно, кто что нашёл.

Чтобы не проверять одно и то же, удобно поделить зоны:

| Кто | Что проверяет |
|---|---|
| 1 | Начало карьеры: двор, соседи, первые покупки ремня и ножей |
| 2 | Телефон: iPhone или Android, удобство кнопок и джойстика |
| 3 | Магазин UDC Store, «Find my part», ссылки на Walmart, баннеры |
| 4 | Поздние уровни: ферма, парк, поместье, гольф, стадион; новые косилки XT2 и V500 |
| 5 | Звук, радио, напитки, виды камеры (C), общее впечатление |

Нашли проблему: в паузе или на экране результатов нажмите **Report a bug / feedback**. Откроется форма на GitHub, где уже указаны день, локация, косилка и устройство; останется описать, что случилось, и приложить скриншот. Нужен бесплатный аккаунт GitHub.

Начать заново: в профиле игры кнопка сброса, или открыть игру в режиме инкогнито.

## Что в игре

- **Реалистичные 3D-модели** косилки и 9 персонажей (Higgsfield), см. `assets/models`.
- **Карьера:** телефон с вкладками Jobs, UDC Store, Garage, Profile. Растёшь по уровням: соседи → фермы → парки → поместья → гольф-клуб → стадион.
- **Требования клиентов:** высота среза, качество, полосы, сбор травы, без повреждений. Оценка от 1 до 5★, от неё зависят деньги и репутация.
- **Износ переходит из заказа в заказ.** Чтобы работать без простоев, нужны запчасти с правильным партномером под свою косилку. Срочный заказ привозит фургон UDC.
- **Диагностика по симптомам**, апгрейды из реальных деталей UDC, сезоны, травосборник, триммер, жажда и напитки.
- **Радио:** вся музыка генерируется кодом игры в реальном времени, чужих записей нет.
- **Остальное:** еженедельный челлендж, конкурент Turf Kings, «Найди свою деталь».

Подробно механики описаны в [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md).

## Устройство кода

Вся игра в одном файле `index.html`: HTML, CSS и JS, без сборки. Three.js r128 подключается с cdnjs.

Основные блоки в `<script>` (ищите по комментариям `// ----------`):

| Блок | Что внутри |
|---|---|
| `PRODUCTS`, `MOWERS` | Товары UDC и косилки с совместимостью. Совместимость брать **только из названий листингов**. |
| `THEMES`, `TIERS`, `SEASONS` | Типы газонов, уровни репутации, сезоны |
| `buildMower`, `person` | Временные модели из примитивов. Будут заменены на `.glb` из `assets/models` |
| `loadWorld` | Генерация газона, препятствий, рекламных щитов, фургона |
| `renderPhone` | Телефон: вкладки Jobs, Store, Garage, Profile |
| `startJob`, `renderShed`, `finish` | Заказ, сарай, оценка клиента |
| `step`, `cutAt`, `footStep` | Физика, покос, триммер |
| `musicTick` | Радио: генератор музыки |

Сохранение лежит в `localStorage`, ключ `udcmow-career`. Чтобы начать заново: Profile → Start over.

## Правила

- Логотипы и надписи других брендов на моделях не используем. Названия моделей показываем только для совместимости, как в листингах.
- Цены в игре игровые. Реальная цена на Walmart или udcparts.com.
- Промокод `MOWPRO10` и форма email пока заглушки.
