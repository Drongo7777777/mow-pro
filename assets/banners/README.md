# Баннеры UDC (тестовые)

Где стоят в игре. Поменять баннер = заменить файл с тем же именем, или поправить `BANNER_AT` в `index.html`.

| Файл | Где в игре |
|---|---|
| `belts-promo.jpg` | Дом/гараж (щит справа от персонажей), гольф (щит слева от поля) |
| `hero-parts.jpg` | Двор соседей и стадион (щит слева от поля) |
| `hero-rider.jpg` | Ферма (щит слева от поля) |
| `hero-deck.jpg` | Парк (щит слева от поля) |
| `parts-lineup.jpg` | Поместье (щит слева от поля) |
| `skinny.jpg` | Над дверью гаража дома, забор за полем на ферме/в парке/на гольфе, борта стадиона, верх вкладки UDC Store |
| `strip-500x100.jpg` | Забор в поместье, борта стадиона, экран результатов после работы |

Щит справа от поля по-прежнему показывает артикул (SKU), который подходит к косилке игрока.
Баннеры в меню ведут на udcparts.com.

Размеры: 3D-щиты 16:9 (1280 px по ширине), полоски — как в оригинале. JPEG, качество 84.
